# Таня Эпик — сайт-портфолио по методологии БЭМ

Контрольная точка 4 по дисциплине «Архитектура программного обеспечения».

Многостраничный сайт-портфолио: веб-разработка, графический дизайн и видеомонтаж.
Вёрстка, классы и файловая структура стилей сделаны по методологии **БЭМ** (Блок, Элемент, Модификатор).

## Страницы

| Страница | Файл | Что на ней |
|---|---|---|
| Главная | `index.html` | Первый экран с видео и «живым» заголовком, приветствие и цифры, бегущие ленты, «Что я делаю», избранные работы, «Как я работаю», контакты |
| Код | `code.html` | Список сайтов со ссылками на рабочие версии |
| Дизайн | `design.html` | Веер работ, слайдер презентации, галерея с фильтром и просмотром работ крупно |
| Монтаж | `editing.html` | Большие работы в Telegram и аккаунты, для которых я монтирую рилсы |

## Как устроен БЭМ в проекте

**Блок** — самостоятельная часть интерфейса: `header`, `hero`, `door`, `case`, `work`, `lightbox`.
**Элемент** — часть блока, отдельно не используется: `door__title`, `case__arrow`, `lightbox__image`.
**Модификатор** — вариант внешнего вида или состояние: `door--code`, `pill--orange`, `nav__link--active`, `fan--open`.

Пример из главной страницы:

```html
<a class="doors__item door door--code reveal" href="code.html">
  <span class="door__tab">✺ Программирование</span>
  <span class="door__body">
    <h3 class="door__title">Разработка</h3>
    ...
  </span>
</a>
```

Здесь на одном теге **микс** трёх сущностей: элемент `doors__item` (положение в сетке), блок `door` с модификатором `door--code` (внешний вид) и блок `reveal` (появление при прокрутке).

Правила, которых придерживается проект:

- стили пишутся только по классам, без селекторов по тегам и id;
- нет цепочек вида `.door .title` — у каждого элемента свой класс `door__title`;
- блок не задаёт себе внешние отступы и положение — это делает родитель через элемент-микс (`intro__stats stats`, `contact__socials socials`);
- скрипт меняет только модификаторы (`scrub__word--active`, `filters__button--active`, `toast--visible`), а как выглядит каждое состояние, описано в CSS блока.

## Файловая структура (по БЭМ)

```
index.html, code.html, design.html, editing.html   — страницы
styles/
  globals.css      — шрифты, переменные (цвета, отступы), сброс стилей
  index.css        — подключает globals.css и все блоки
blocks/            — каждый блок в своей папке
  header/header.css
  hero/hero.css
  door/door.css
  ...              — всего 50 блоков
scripts/main.js    — общий скрипт для всех страниц
images/, video/, fonts/
```

## Запуск

Сайт статический, сборка не нужна. Достаточно открыть `index.html` в браузере
или выложить папку на GitHub Pages.
